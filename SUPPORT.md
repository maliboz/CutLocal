# Support

CutLocal is a community-maintained open-source project and comes without a
warranty or guaranteed response time.

- Use **Issues** for reproducible bugs and approved feature proposals.
- Use **Discussions** for questions, ideas, workflows, and community help once
  Discussions are enabled on the repository.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.
- Read [README.md](README.md), [docs/release.md](docs/release.md), and existing
  issues before opening a new report.

When asking for help, include the CutLocal version, operating system and
architecture, package type, CPU/GPU, selected model/provider, input image
dimensions, and a sanitized log excerpt. Do not upload private images unless you
intentionally choose to make them public.
