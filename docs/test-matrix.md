## Current golden tolerance

The tiny test ONNX model computes a deterministic channel mean; it is generated by test code and is not a production weight. A horizontal gradient is processed end to end. The output alpha is compared to the analytic gradient with MAE ≤ 6/255, thresholded IoU ≥ 0.98, and no local backward step greater than 6/255. These limits cover bounded resampling differences without accepting coordinate, channel, or layout errors.

Real U2NetP acceptance adds an open fixture image plus the exact upstream Python/rembg output. Target tolerances will be set from measured CPU runs, not guessed. Pixel-perfect equality is not assumed across Pillow and Skia interpolation.
